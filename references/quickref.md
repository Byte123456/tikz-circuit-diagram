# 接口速查 —— 写图前先读这一页

宏签名、端子命名、自动布局的产出坐标名、以及每条规矩背后的原因。
**不必读 `stm32tikz.sty` 源码**（900+ 行，注释给改工具的人看）。

---

## 1. 画线

| 宏 | 用途 |
|---|---|
| `\Wire{a}{b}` | 画一段导线。**不检查正交**——斜线照画不误，但会被电气门报出来 |
| `\WireH{a}{b}` | 水平走线，**声明两端同 y**。斜了会被报 `[非正交]` |
| `\WireV{a}{b}` | 竖直走线，**声明两端同 x**。斜了会被报 `[非正交]` |
| `\Junction{点}` | 结点。**交叉的两条线默认不连通**，只有画了结点才算连上 |

**接线一律用 `\WireH`/`\WireV`，别用裸 `\Wire`。** 斜线会被连通性分析**整个
丢弃**（斜线交叉算不算连无从判定）—— 一条斜着画出、两端没真接上的线会被当成
不存在，图看着连了、检查器说没问题。

`a`/`b` 是**点表达式**，支持：节点名（`R1end`）、`节点.锚点`（`Q1.C`）、
命名坐标（`ledA`）、裸坐标（`1cm,2cm`）、calc 表达式（`$(Q1e)+(0,-1cm)$`）。

⚠ **不写外层括号**：`\WireH{A}{B}` 而不是 `\WireH{(A)}{(B)}`。
   宏内部自己补括号；带括号会变成 `((A))`，报 `No shape named '(A'`。
   （唯一例外：`\Anno` 的位置参数**要**带括号，它直接转交给 `\node ... at`。）

⚠ **calc 表达式里节点名必须带括号**：`$(Q1e)+(0,-0.8cm)$`，不是
   `$Q1e+(0,-0.8cm)$` —— 后者 pgf 把 `Q1e` 当数学函数名，报
   `File ended while scanning use of \tikz@cc@parse@factor`。

⚠ 两端重合会记成 `M|零长导线`（记账警告）。不影响连通性，但说明你
**以为两个点是分开的**——通常取错了锚点。

> 侧车文件（`<jobname>.net`）的完整记录格式与连通规则见 `sidecar-format.md`。
> **画图不需要读它**——上面这几行就是画图要守的全部规则。

## 2. 器件

通用形式，需要复杂选项时用它：

```latex
\cPart{名}{circuitikz键}{起点}{终点}{选项}
```

现成封装：

| 宏 | 例子 |
|---|---|
| `\cR{名}{起}{终}` | `\cR{R1}{A}{B}` |
| `\cRes{名}{起}{终}{值}` | `\cRes{R1}{A}{B}{10K}` （带值标签） |
| `\cC` / `\cCap{名}{起}{终}{值}` | `\cCap{C1}{A}{B}{100nF}` |
| `\cD` / `\cLED` / `\cPD` | 二极管 / LED / 光敏管 |
| `\cL` / `\cSW` | 电感 / 开关 |
| `\cNPN{名}{位置}` | 端子 `.b`/`.c`/`.e`；`anchor=B` 落在给定点 |
| `\cGND{点}` / `\cVCC{标签}{点}` | 地 / 电源符号 |
| `\CoilNode{名}{中心}{显示文字}` | 继电器线圈，端子 `.t`/`.b` |
| `\Contacts{名}{中心}` | 继电器常开触点，端子 `.com`/`.no` |
| `\MCU{名}{x}{y}{宽}{高}{说明}{引脚表}` | 引脚表 = `{PA0/0cm, PA1/-0.9cm}` |
| `\MCUauto{名}{x}{y}{宽}{高}{说明}{间距}{引脚名列表}` | 引脚等距自动排，见 §5 |

### 端子命名：统一 `.a` / `.b`

`a` = 画线的**起点**，`b` = **终点**。**刻意不用 `.l/.r/.t/.b`**——
那四个会随摆放方向改变含义，调用点写错时"端子还在、只是接错边"，很难发现。

引用端子用坐标别名：`R1a` / `R1b` / `Q1c` / `Q1e`（在宏里一处定义）。
**不要写 `R1start`**——后缀易记错。

> **方向语义（实测）**：`R`/`C` 两端无极性；`D`/`leD`/`photodiode`
> **a = 阳极(+)，b = 阴极(−)**，三角形由 a 指向 b。所以"阴极朝上"就要
> **从下往上画**（起点在下方）。

### 值标签与 `\LogLabel`

```latex
\cRes{R1}{A}{B}{10K}\LogLabel{R1}
```

`\LogLabel` 把 circuitikz 生成的 `⟨名⟩label` 节点的**真实排版盒**收进侧车，
排版门"文字压线/压器件"才看得见它。**漏了它 = 门禁对这一片瞎。**
器件名拼错时侧车会出 `M|找不到 label 节点`，别忽略。

### 器件名必须 ASCII

`\cRes{R1}`、`\CoilNode{K1}`。中文只放显示标签（`l=` 或 `\Anno`）——
`\pgfpointanchor` 解析 `K1线圈.t` 会把中文当数学函数名。

## 3. 标注

### `\AnnoAt` —— 位置交给 `place.py`（**首选**）

```latex
\AnnoAt{键}{样式}{参考点}{角次序}{文字}
```

- **键**：ASCII `[a-z0-9_]`。改了键 = 换一个标注，旧偏移会丢。跟着**内容**命名
  （`pd1rev` 而不是 `anno3`），免得挪了标注键名就失去意义。
- **参考点**：**不带括号**。`PD1.west` / `ledA` / `(3,2)`。
- **角次序**：往参考点的哪个方向摆，逗号分隔的**候选表**，**按序试**。
  `west,south west,east` 这样给多个能显著提高一次收敛率（元件左上方挤，
  `west` 不行时 `east` 往往就有位置）。给 `{}` 表示不换方向、只向下拉开。
- **样式**：只给字形/对齐，**不要写 `anchor=`**（anchor 由摆位决定）。

`place.py` 生成的偏移写进 `auto_offsets.tex`；`.tex` 里要有一行
`\InputAnnoOffsets{auto_offsets.tex}`（文件不存在时全部退化成 0 偏移，
编译照常）。

**钉死某个标注**（位置有语义、不希望被自动挪走）：

```bash
python <skill>/scripts/place.py circuit.net --pin ct1name=0,-30   # 单位 pt
```

### `\AnnoPack` —— 多行说明块（**别手猜坐标**）

```latex
\coordinate (noteCol) at (9.7,-15.4);        % 列顶：第一块的锚点
\AnnoPack{note1}{ann, align=left, text width=8.2cm}{noteCol}{第一块...}
\AnnoPack{note2}{ann, align=left, text width=8.2cm}{noteCol}{第二块...}
```

不同方面：`\AnnoAt` 是"相对**元件锚点**朝某方向偏移"，而说明块**没有元件锚点**
（它是版式文字，不"属于"某个器件），它要的是**一列里顺序堆叠**。
`\AnnoPack` 给一个**列顶坐标**，`place.py` 读侧车里每块的**真实高度**，
按 `高度 + 间隙` 依次往下排。

**为什么必须用它**：说明块很高（单块可达 229pt），手猜坐标一旦撞上就是大片
重叠，而且"差一点点"时排版门也未必报。

⚠ 样式里**不要写 `anchor=`**（堆叠按 `north west` 对齐列的左边界，写了会错位）。
⚠ 同一列的多块**共用同一个列顶坐标** —— place.py 就是按"锚点相同"分组的。
⚠ 列位置（那个坐标）仍由你定；place.py 只负责"列内怎么排"，不负责"列放哪"。

### `\Anno` —— 手写位置（只给绝对定位的零散文字）

```latex
\Anno{ann, anchor=east}{($(R1.west)+(-0.18cm,0)$)}{R1}
```

⚠ 位置参数**要带括号**（与 `\WireH` 相反，它直接转交给 `\node ... at`）。
普通标注用 `\AnnoAt`，多行说明块用 `\AnnoPack`；两者都不适合时才用它，
`place.py` 会把它当**固定障碍物**。

### 样式

`ann`（普通小字，灰）/ `annb`（小字加粗，黑）。两者用了就自动登记进侧车。

## 4. 自动布局

### `\Chain` —— 串联支路

```latex
\Chain{前缀}{起点}{步进向量}{元件表}
\Chain{LEDS}{ledStart}{1.6cm,0}{R3/R/1K, LED1/leD/{}}
```

元件表 = `{键/符号/值, ...}`，**值留空则不标注**。

竖放就用同一条宏、改步进向量：`\Chain{V1}{T}{0,-1.6cm}{R/R/10K, D/D/{}}`。

**产出坐标名**（⚠ 前缀是**直接连写**的）：

| 名字 | 是什么 |
|---|---|
| `⟨前缀⟩R3` | 该元件的**节点名**（可取 `.north`/`.south` 摆东西） |
| `⟨前缀⟩R3a` / `⟨前缀⟩R3b` | 该元件两端 |
| `⟨前缀⟩start` / `⟨前缀⟩end` | 路径起点 / 末端 |

所以 `\Chain{LEDS}{...}{R3/R/1K,...}` 产出的是 **`LEDSR3a`**，不是 `R3a`。

### `\Bus` —— 母线挂支路（一个节点接 3~4 个元件）

```latex
\Bus{前缀}{母线x}{上y}{下y}{侧}{支路表}
\Bus{B1}{12.4}{-5.2}{-9.9}{left}{D2/D/0.30/1N4148, K1/L/0.62/5V}
```

支路表 = `{键/符号/位置比/值}`，位置比 0..1（母线上自上而下的高度）。
侧 = `left` | `right`。产出 `⟨前缀⟩top/bot` 与每条支路的
`⟨前缀⟩⟨键⟩a/b`、`⟨前缀⟩⟨键⟩tap`。

⚠ **元件一律离母线让开**（内部已做）——骑在母线上会纵穿元件本体 = 穿体 = 旁路。

⚠ **不适用反并联**：那种结构要两个器件竖放才看得出关系，用 `\Chain` 竖放
+ 导线接成并联。

### `\RowAt` / `\ColAt` / `\Span` —— 消除手抄坐标

```latex
\RowAt{新名}{参考点}{x}     % 取参考点的 y，配一个新 x
\ColAt{新名}{参考点}{y}     % 取参考点的 x，配一个新 y
\Span{新名}{A}{B}           % = A |- B，但会登记进侧车（匿名坐标事后没法引用）
```

**同一个数字别写两遍**：

```latex
% 坏: -3.9 抄了 4 遍, 改行漏一处就错位
\coordinate (filtL) at (3.4,-3.9);
\cRes{R4}{filtL}{5.5,-3.9}{10K}
\coordinate (adcNode) at (6.6,-3.9);

% 好: 这一行只有一处定义
\coordinate (adcRow) at (0,-3.9);
\RowAt{filtL}{adcRow}{3.4}
\RowAt{r4R}{adcRow}{5.5}
\RowAt{adcNode}{adcRow}{6.6}
```

**错位几 pt 是看不出来的**——不压字、不重叠、线也不近到报警，排版门一条都不报，
但图上是"这几个元件没对齐"。

行列交点也可以用原生的 `A |- B` / `A -| B`（`A |- B` = A 的 x、B 的 y），
`\Span` 的额外好处是登记进侧车、事后能引用。

### `\MCUauto` —— 引脚等距自动排

```latex
\MCUauto{名}{x}{y}{宽}{高}{说明}{间距}{引脚名列表}
\MCUauto{MCU}{-1.2}{-12.2}{3.0cm}{3.4cm}{STM32F103C8T6}{0.9cm}
    {\PinADC, \PinDrive}
```

引脚只给名字，y 偏移按间距等距、整体居中，**列表第一个在最上面**
（与数据手册的引脚图画法一致）。引脚坐标名 = `⟨前缀⟩⟨引脚名⟩`（如 `MCUPA0`），
要跟别的器件对行就用 `A |- MCUPA0` 取交点，别手算 y。

⚠ `\MCU`（手写偏移版）的引脚表**不能省略偏移**：实测 `{PA0, PA1}` 会让 `\pdy`
回退成引脚名本身，`{PA0/, PA1/}` 也一样，两种都会把引脚名当节点去找。

## 5. 网络断言与符号

| 宏 | 用途 |
|---|---|
| `\Expect{元件名.端子}{目标}` | 声明"该端子应在哪张网"。目标可写网络名（`+5V`/`GND`）或 `元件名.端子`。**唯一能抓「接到错的节点」的手段** |
| `\Power{网络名}{点}` | 电源/地符号的**连接点**（同名自动同网） |
| `\NetTag{号}{点}` | 网络标签，同号相连 |
| `\Junction{点}` | 结点（交叉连通标记） |

### ⚠ 写 `\Expect` 之前，先看网表

`build.py` 每次都会自动打印紧凑网表；网多时手动跑全量：

```bash
python <skill>/scripts/check_tex_net.py --show-nets circuit.net
```

**别凭电路直觉猜网结构。** 连通性分析里**元件本体是网络边界**：隔着电阻本体
两点就是两张网。实测在开漏驱动图里按"上拉应落在基极"的直觉写 `\Expect` 被
报 3 条 `[接错]`——门禁报得对，上拉与基极之间隔着一个限流电阻的本体。
**先看网、再写断言，一次就过**；这个顺序还能帮你发现真实的接错。

⚠ `\Expect` **抓不住"同一元件两端接反"**——两极接的还是那两张网。
那个只能靠人眼看图，见「极性」一节。

## 6. 调试与自检

build/check/selftest 的命令见 SKILL.md「一键闭环」与「两道门各查什么」两节；
这里只列 SKILL 没有的调试宏。

| 宏 / 命令 | 用途 |
|---|---|
| `\ShowNames` | 打开后把自动生成的坐标名 `\typeout` 出来，并写进侧车 `N\|` 记录（可直接 grep 侧车）。**默认关闭** |
| `\DumpCanvas` | 登记画布范围。**必须在 `\end{tikzpicture}` 之前调用一次** |
| `\LogLabel{名}` | 把值标签排版盒收进侧车 |

### 要测符号几何？先查表，再探针

**绝大多数情况不用探针** —— 尺寸已经在 `references/geometry.md` 里了
（每个符号的端子偏移、本体宽高、最小跨度、值标签高度）：

```bash
python <skill>/scripts/gen_geometry.py           # 重新生成（改了符号几何后）
python <skill>/scripts/gen_geometry.py --check    # 校验表是否过期
```

真要临时测新符号，用 `--probe` 而不是手写探针（手写要自己设 TEXINPUTS、
翻日志找 `\typeout`、手抄结果 —— 三个坑它都省了）：

```bash
python <skill>/scripts/build.py x --probe probe.tex
python <skill>/scripts/build.py x --probe -        # 从 stdin 读
```

它用**与正式 build 完全相同**的编译环境编译探针，打印侧车摘要
（本体盒/端子/文字盒/记账警告）。探针里能编译通过的，正式图里一定能通过。

## 7. 极性 —— 门禁查不出，必须人眼

任何连通性检查都**查不出方向**。两根线都接在正确端子上时，连通性完美、
全套检查报 0。交付前必须用 `--show-nets` 逐条读：

| 器件 | 正确方向 |
|---|---|
| LED | 阳极朝高电位侧（电流 a→b） |
| 续流管（跨线圈） | 阴极朝电源侧、阳极朝被开关的节点 |
| 光敏管 / 光电二极管 | **反偏**：阴极朝高电位侧 |
| 电解电容 | 正极朝高电位侧 |
| 三极管 | 反相：IO 高→导通（与"直连电阻"同相相反） |

**开漏输出 + 外部上拉**又是"写 1 点亮"，等于把三极管的反相翻了回来——
同一张图上混用两种驱动方式时最容易搞错。
